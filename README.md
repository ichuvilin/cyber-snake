# 🐍 КиберЗмейка

Консольная игра «КиберЗмейка», написанная на Go с использованием библиотеки `termbox-go`.

Игрок управляет киберзмейкой, собирает еду, увеличивает свой счёт и уровень. На игровом поле появляются вирусы, столкновение с которыми приводит к окончанию игры.

## Возможности

- Управление змейкой с клавиатуры
- Сбор еды и увеличение длины змейки
- Система очков
- Повышение уровня каждые 5 очков
- Появление дополнительных вирусов при повышении уровня
- Проверка столкновений со стенами, собой и вирусами
- Экран Game Over
- Возможность перезапуска игры

## Требования

- Go 1.21 или новее
- Терминал с поддержкой Unicode

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/username/cyber-snake.git
cd cyber-snake
```

## Сборка и запуск

Для сборки проекта выполните:

```bash
go build -o cyber-snake
```

После успешной сборки запустите игру:

```bash
./cyber-snake
```

Также игру можно запустить без предварительной сборки:

```bash
go run .
```

## Управление

| Клавиша     | Действие                        |
| ----------- | ------------------------------- |
| `↑` / `W`   | Движение вверх                  |
| `↓` / `S`   | Движение вниз                   |
| `←` / `A`   | Движение влево                  |
| `→` / `D`   | Движение вправо                 |
| `Q` / `Esc` | Выход из игры                   |
| `R`         | Перезапуск после окончания игры |
